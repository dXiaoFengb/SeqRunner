# 正常 Git 提交

- 何时读取：首次配置 Git、需要核验忽略规则，或按策略准备本地提交时；已知 Git 不可用的日常开发跳过本模块。
- 职责：Git 初始化前置、忽略核验、暂存保护、提交证据与正常检查点。
- 必要前置：`CONSTRAINTS.md` 的 Git 策略、资产与记录边界，当前任务范围及实际验证结果。
- 输出位置：适用忽略配置、`CONSTRAINTS.md` 核验结论、本地提交、分类对话记录及 `对话记录/06-Git提交备份.md` 实际结果。

本模块内路径以项目根目录为基准；引用只作导航，仅在对应动作触发时读取。

## 初始化与忽略核验

新项目先确认目标目录没有现有仓库或索引，并按已确认技术栈准备 `.gitignore`；不重复初始化已有仓库。初始化后、首次暂存前核验实际忽略效果和跟踪状态。技术栈未确认时不预置技术栈无关的忽略文件，不能制造已保护的错觉。

使用 Git 时核验凭证类文件（如 `.env`、`*.key`、`*.pem`、本地环境文件和配置覆盖文件）、用户资料和产物受到已确认策略保护；整个 `对话记录/` 必须被忽略，且没有其中的已跟踪文件。Windows EXE 项目覆盖 `/产物/工作/`、`/产物/验证/` 及实际缓存和中间产物；发布目录按已确认流程处理，默认不提交大型二进制。发现已跟踪的敏感、记录或其他禁止提交内容时停止相关提交并说明，不自行移除索引或改写历史。

技术栈、交付形态、实际产物或缓存目录、记录保存位置或纳入策略、凭证等忽略对象，以及生效忽略规则发生可能影响核验的变化时，原“已核验”不再直接适用。执行者须先退回“待确认”，重新核验忽略和跟踪状态；无法判断是否受影响时也先退回并说明。该退回属于收紧，不更新长期约束的最后确认日期与来源。只有复核通过才可改回“已核验”；未通过或无法完成不得提交，用户当次确认不替代核验。

来源或用途不明的文件先按 `CONSTRAINTS.md` 确认其读写、纳入 Git 和登记要求，只读引用不免除核验。不使用 Git 时不创建或核验 `.gitignore`，对应结论为“不适用”。

## 提交条件与操作

使用 Git、项目已初始化、`.gitignore` 已核验、策略为自动提交且作者身份可用时，本轮可明确归属的持久改动完成其他必要检查及适用 AI 审核后，建立本地检查点。即使身份或忽略前置尚未满足，也先完成适用前置检查；身份不可用时只索取配置所需信息。手动提交或不提交遵守所选策略；除此之外仅按当次明确要求或有效长期预先授权提交。

源码预览失败本身不阻止满足其他条件的检查点；尚未人工验收的新改动照实记录，不冒充通过。首个源码入口未实现或缺少 EXE 也不单独阻止留痕。只有本地对话记录、没有可提交文件时不创建空提交。

任务执行模块调用前置核对时，只处理仓库、身份和忽略核验，不提前暂存或提交。初始化、忽略规则及核验状态的修改也须在写入前保存允许范围的基线。实际提交前，先完成本轮应有的任务、版本、说明、验收步骤与交接更新，再按备份规则核对最终清单与实际拟提交内容；不能先提交再把这批收尾改动算入原检查点。发现内容仍在变化时，返回任务收尾并重新形成受影响的备份、验证和暂存证据；备份缺项按实际记录，不冒称完整。

1. 检查 `git status` 和 `git diff --cached`，只暂存可明确归属的具体路径；不用 `git add .` 或 `git add -A`。保护用户已有暂存及部分暂存选择，无法安全区分时停止，不清空或重建暂存区。
2. 在本地 `对话记录/04-问题、风险与恢复.md` 按记录模板保存原分支、HEAD、预计范围、验证结果、内容指纹和已有暂存归属；最终暂存后记录并复核 Git tree ID。最终暂存含无关内容或无法证明内容与验证对应时不提交。对话记录、验证包和构建工作目录不得暂存。
3. 检查点主题为 `检查点:<版本或不适用> <中文改动摘要>`。涉及本轮开发版本更新时包含 `VERSION.md`；纯非功能改动不强制改版本。检查点不打包、不发布。
4. 成功后核对实际提交，仅向 Git 忽略的分类记录和备份索引追加提交主题、哈希及实际状态；不为补写提交结果回改冻结清单或已提交文件。之后确需改受跟踪文件时，按任务执行模块作为新改动保存基线、验证、备份及按策略提交，不把后改内容冒充先前已提交。纯收尾修正不重复升功能版本；记录始终不进入 Git，不伪造提交、版本或验证证据。

初始化、运行或提交前置失败时保存实际原因、未提交状态和现有证据，继续安全开发及本地留痕，不擅自改变 Git 策略。已确认 Git 不可用后不反复催修或尝试，后续日常直接使用本地备份和记录。提交失败当轮不盲目重试；需确认提交结果或用户要求修复恢复时才读取 `规则/Git恢复.md`。本模块不授权推送、改写历史、清理工作区或外部写入。
