# AUTO-MAS 风格整改提示词

AUTO-MAS 的界面属于深色企业级运维控制台 / Windows 桌面管理后台风格：左侧导航稳定，主内容使用高信息密度的卡片、表格和分隔线，蓝色承担主要操作，红色承担危险操作，字段说明使用上下文提示。其控件语言接近 Ant Design Vue，但不是严格的 Material Design 或 Fluent Design。

```text
为“顺序任务调度器”重构指定页面，参考 AUTO-MAS 的信息层级与可发现性，但不得复制 AUTO-MAS 的源码、图标、图片、资源或原文案。

视觉方向：
- 深色企业级运维控制台 / Windows 桌面管理后台。
- 左侧导航稳定、主内容区克制留白、以卡片、表格和分隔线表达层级。
- 主操作使用清晰的蓝青色；删除、停止等危险操作使用低饱和红色描边或按钮；普通操作保持深色描边。
- 不使用大面积渐变、装饰性玻璃效果、营销式大标题或无意义的圆角卡片堆叠。
- 颜色、边框、悬停、焦点、禁用态必须完整；所有输入框、下拉框和浮层保持统一深色主题。
- 中文文案短句、直接、可操作；空状态说明下一步，不展示技术错误或内部 JSON。

布局原则：
- 一个业务对象对应一张独立卡片或一行，编辑、删除、启动等操作必须紧邻其所属对象，不能依赖含糊的全局选中状态。
- 页头只放页面级操作；对象级操作跟随对象卡片；编辑页只展示当前对象配置，不混入其他对象选择列表。
- 表格用于可排序、可比较的重复数据；卡片用于概览、状态和对象级操作。
- 保持桌面高信息密度，宽度不足时转为纵向条目，不产生横向溢出或遮挡关键按钮。
- 拖拽时显示完整行或完整卡片预览；键盘提供等价排序和操作路径。

交互与可访问性：
- 说明使用字段标签后的“？”帮助按钮，支持悬停、点击、键盘聚焦、Esc、点击外部关闭，并提供 aria-label、aria-describedby、role=tooltip。
- 焦点必须可见；危险操作明确；运行锁定时所有会修改配置的控件禁用并说明原因。
- 动画只反馈用户操作，例如展开、收起、拖拽或保存；不使用无意义的循环动效。
```
