# Windows 人工验收步骤

自动化测试不代替此验收。日常使用请双击便携 EXE（生成后位于本机被忽略的 `release/`）；`启动器.bat` 只用于开发环境检查。若开发检查提示缺少环境，按提示安装本项目依赖后重新启动。

本轮待验收文件为 `release\\顺序任务调度器-0.1.0-portable.exe`，SHA-256：`8C3F53EC6F0D653CC8DE31A45F8FF4642F172C4B3EBB2A06B6A48F8122C92A2D`。它是本地构建证据，不是发布物。请在普通 Windows 桌面会话中进行以下验收；当前受限自动化环境无法创建 Electron 的单实例锁，因此不能替代本步骤。

1. 双击该 EXE。预期只出现应用主窗口，不出现命令提示符黑框；在“设置”确认后端状态为已连接，且同级 `data\\logs\\` 已出现应用日志。若启动失败，展开诊断并记录其中文提示与日志末尾内容，停止后续步骤。
2. 新建一个队列，添加两个临时测试任务。可使用 Python 解释器作为程序路径，并以 `-c` 加短脚本作为参数；不要配置真实业务程序。
3. 让第一项启用“人工确认”。手动开始队列，确认第一项已启动后点击“确认完成”。观察其受管进程被关闭，界面显示十秒冷却，第二项随后才启动。
4. 分别用零退出、成功日志和失败日志验证完成来源、失败后继续和日志摘要。日志测试应使用临时日志文件，确认启动前已有的成功文本不被误判。
5. 为队列添加接下来一分钟的定时槽，确认它从第一项启动；在队列运行期间命中另一槽，确认界面/日志提示“因忙跳过”，且没有排队重跑。
6. 运行时点击“全局停止”，确认当前受管 PID 被收尾、冷却取消且不启动下一项；随后关闭主窗口，确认应用退出且没有遗留本轮后端。
7. 在“队列”页分别选择五个预设并点击“选择软件”。MAA 与绝区零一条龙应只接受对应 EXE；MaaEnd、三月七小助手和 BetterGI 应显示“需人工确认”。故意选择不匹配 EXE，确认界面切换为“通用程序”而非套用错误规则。
8. 缩小窗口至约 960px，确认导航收缩、任务表单改为单列且页面不横向溢出；打开“设置”确认连接、诊断及数据边界可见。
