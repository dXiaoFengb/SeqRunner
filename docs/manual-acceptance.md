# Windows 人工验收步骤

自动化测试不代替此验收。日常使用请双击便携 EXE；`启动器.bat` 只用于开发环境检查。若开发检查提示缺少环境，按提示安装本项目依赖后重新启动。

本轮独立验证包为 `portable-validation-v031\\electron\\顺序任务调度器-v0.3.1-portable.exe`，其 SHA-256 为 `288C69E2FEA692370CAA267943272853A6549544E00D533D531D87816B4E83E9`。它包含 v0.3.0 的单软件脚本功能，已通过隐藏启动健康检查；该包仅用于本地验收，不代表发布，也不覆盖此前任一验证包。

1. 双击 `portable-validation-v031\\electron\\顺序任务调度器-v0.3.1-portable.exe` 打开应用。预期只出现应用主窗口，不出现命令提示符黑框，且绝不显示 `ERR_FAILED (-2) loading ...\\Temp\\...\\index.html`；原生标题栏和左侧品牌区均显示“顺序任务调度器 v0.3.1”，设置页保留“开发版本 v0.3.1”。在“设置”确认 API 为在线、实时状态已连接，且 EXE 同级 `data\\logs\\` 已出现应用日志。若启动失败，展开诊断并记录其中文提示与日志末尾内容，停止后续步骤。
2. 保持应用空闲至少 3 分钟。预期实时状态不反复跳为“重试中”；如确有断开，诊断应显示关闭码/原因/下一次时间，且 API 仍在线时“新建脚本”、保存、运行和停止不会被禁用。
3. 在“脚本”页新建两个软件脚本。每次新建应直接生成一张“新程序”软件卡，而非空脚本或“添加程序”入口。可使用 Python 解释器作为程序路径，并以 `-c` 加短脚本作为参数；不要配置真实业务程序。确认首页每条卡只显示拖拽把手、软件名、路径摘要、预设、状态、“编辑脚本”“运行”“更多”，不显示程序数、队列、程序预览、展开控件或可编辑字段。点击“编辑脚本”必须进入该软件唯一的一份完整配置表单，页面不存在“程序顺序”“选择要编辑的程序”或“添加程序”。返回后仍回到软件卡列表。复制软件脚本后检查其定时槽未被复制。拖动软件卡或在“更多”中使用“上移/下移”后关闭再打开，确认排序已保存。
4. 建立包含两项临时程序的脚本，让第一项启用“人工确认”。手动开始后点击“确认完成”。预期按钮立即变为“确认已接收”，顶部“运行中心”依次显示“正在请求程序正常关闭”“正在收尾受管进程”以及“第 N 项已完成，X 秒后启动下一程序”；十秒倒计时每秒可见变化，第二项只在倒计时结束后启动。第二项成功或失败收尾后，不再显示十秒倒计时，直接显示“整轮执行完成”（失败时提示存在失败项）。
5. 两个软件脚本都完整配置后，点击“运行全部脚本”，确认严格按软件卡顺序串行执行，并在历史中显示所属软件脚本。故意清空任一路径后再点击，预期整轮被阻止且列出问题，不得只运行其余软件；“计划”页仍只能为一个软件脚本配置时间。若升级前存在多程序脚本，先备份 `data/config.json`，启动后确认其被拆分为多个软件卡、原组合定时槽已清空并出现中文迁移提示。
6. 分别用零退出、成功日志和失败日志验证完成来源、失败后继续和日志摘要。日志测试应使用临时日志文件，确认启动前已有的成功文本不被误判。存在失败项时，确认运行中心显示最终 `N/N`、失败程序所属脚本和错误摘要；点击“查看失败详情”后应跳转到历史页并展开本轮失败项，显示完成来源、退出码与日志摘要。
7. 在“计划”页为脚本添加接下来一分钟的定时槽，确认它从第一项启动；在脚本运行期间命中另一槽，确认界面/日志提示“因忙跳过”，且没有排队重跑。
8. 运行时点击“全局停止”，确认当前受管 PID 被收尾、冷却取消且不启动下一项；随后关闭主窗口，确认应用退出且没有遗留本轮后端。
9. 在独立编辑页分别选择五个预设并输入或点击“选择软件”选择对应 EXE。选择模板后，立即确认“模板成功规则 / 模板失败规则”以只读列表显示；匹配 EXE 后 MAA 与绝区零一条龙应填入软件名（仅原为“新程序”时）、工作目录、日志路径、参数、600 秒超时与完成方式。展开“添加自定义规则”后，确认自定义成功/失败规则独立于模板规则；输入与模板相同的规则应被拒绝。MaaEnd、三月七小助手和 BetterGI 应填入路径/工作目录、已证据参数与人工确认回退。故意输入不匹配 EXE，确认路径仍显示、预设证据被清除、运行被禁用，并只能通过“重新选择”或明确点击“切换为通用程序并保存”后继续；不得静默套用预设规则。
10. 打开脚本卡“更多”菜单，确认其覆盖于卡片上方、不被裁剪、不挤动相邻脚本；点击空白处或按 Esc 后关闭并将焦点返回“更多”。滚动独立编辑页，确认左侧导航始终固定，顶部运行中心在运行时始终可见；缩小窗口至约 960px，确认导航收缩、任务表单改为单列且页面不横向溢出；打开“设置”确认版本、连接、诊断及数据边界可见。
