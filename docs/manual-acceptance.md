# Windows 人工验收步骤

自动化测试不代替此验收。请在项目根目录双击 `启动器.bat`；若它提示缺少环境，按提示安装本项目依赖后重新启动。

1. 新建一个队列，添加两个临时测试任务。可使用 Python 解释器作为程序路径，并以 `-c` 加短脚本作为参数；不要配置真实业务程序。
2. 让第一项启用“人工确认”。手动开始队列，确认第一项已启动后点击“确认完成”。观察其受管进程被关闭，界面显示十秒冷却，第二项随后才启动。
3. 分别用零退出、成功日志和失败日志验证完成来源、失败后继续和日志摘要。日志测试应使用临时日志文件，确认启动前已有的成功文本不被误判。
4. 为队列添加接下来一分钟的定时槽，确认它从第一项启动；在队列运行期间命中另一槽，确认界面/日志提示“因忙跳过”，且没有排队重跑。
5. 运行时点击“全局停止”，确认当前受管 PID 被收尾、冷却取消且不启动下一项。

记录每一步的观察结果、Windows 版本和任何异常；真实程序路径、参数、日志位置与完成规则仍需用户另行提供。
