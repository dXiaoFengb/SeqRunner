# 日志通俗显示依据

仅在展示时识别日志文本，不作为任务完成判断。无法识别的行保留原文。采集时间与日志正文内的时间分别标注；识别规则对格式变化保持保守。

| 来源 | 可识别的例子与适用条件 |
| --- | --- |
| MAA | [官方仓库日志样例](https://github.com/MaaAssistantArknights/MaaAssistantArknights/issues/17961) 中 `Bootstrapper` 的 GUI 启动与版本行；这些只表明界面启动或版本，不代表任务完成。 |
| 绝区零一条龙 | 本地只读参考 `AUTO-MAS/app/task/ZzzOd/push_log.py` 与[官方仓库日志样例](https://github.com/OneDragon-Anything/ZenlessZoneZero-OneDragon/issues/2086) 中的指令级执行成功、失败；展示为该指令结果，不推断整轮结果。 |
| MaaEnd | 本地只读参考 `AUTO-MAS/app/task/MaaEnd/push_log.py` 描述的带时间戳任务开始、完成、失败行；参考项目指出这些行通常来自 stdout，本应用只读取用户已配置的文件。 |
| 三月七小助手 | 本地只读参考 `AUTO-MAS/app/task/HSR/tools/log_detect.py` 及[官方仓库日志样例](https://github.com/moesnow/March7thAssistant/issues/1134) 中能确定含义的中文提示；不推断整轮结果。 |
| BetterGI | 本地只读参考 `AUTO-MAS/app/task/BetterGI/AutoProxy.py` 与[官方仓库日志样例](https://github.com/babalae/better-genshin-impact/issues/1808) 中，一条龙结束信息及前一行来源；结束不表示每个子任务都成功。 |

上游版本可能改变格式。未找到可靠匹配依据的内容使用原文，不读取软件目录或自动添加日志路径；原始视图不进行转译。
